# Siddharth Shukla - Portfolio

Personal portfolio website built with React.js, Bootstrap, and custom CSS showcasing projects, skills, education, leadership, and experience.

## Featured Projects

- **CodeSync**: Real-Time Collaborative Code Editor (React, TypeScript, Node.js, Express, Socket.io, MongoDB, Monaco Editor, Gemini 2.5 Flash, Docker)
- **TxnIQ**: AI Transaction Processing Pipeline (FastAPI, Celery, Redis, PostgreSQL, SQLAlchemy, Docker Compose, React)
- **Mockly**: AI Mock Interview Platform (React, Node.js, Express.js, MongoDB, Gemini 2.5 Flash, JWT, REST APIs)
- **MEGHDOOT**: Smart Irrigation & Monitoring System (IoT, ESP32, Node.js, REST APIs, Sensors, Machine Learning)

## Development

```bash
# Install dependencies
npm install

# Run locally
npm start

# Build for production
npm run build
```
